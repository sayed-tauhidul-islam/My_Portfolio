# 🚀 Tauhidul's Portfolio

A modern, professional full-stack developer portfolio built with Next.js 15, TypeScript, and Tailwind CSS. Features a stunning dark theme, animated mouse trail, and comprehensive showcase of projects, skills, and experience.

![Portfolio Preview](https://img.shields.io/badge/Next.js-15-black?style=for-the-badge&logo=next.js)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue?style=for-the-badge&logo=typescript)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-cyan?style=for-the-badge&logo=tailwindcss)

## ✨ Features

- **🎨 Modern Design**: Sleek dark theme with cyan/blue accents and gradient effects
- **🖱️ Interactive Mouse Trail**: Blue dot trail that follows cursor movement
- **📱 Fully Responsive**: Perfect experience on desktop, tablet, and mobile devices
- **🚀 Multi-Page Navigation**: Separate landing pages for Home, About, Projects, Skills, and Contact
- **⚡ Fast Performance**: Built with Next.js 15 for optimal speed and SEO
- **🎭 Smooth Animations**: Hover effects, transitions, and scroll animations throughout
- **💼 60+ Skills Showcase**: Comprehensive breakdown with animated progress bars
- **🔨 12+ Projects**: Categorized portfolio with filtering capabilities
- **📧 Contact Form**: Interactive form with validation
- **🌟 Testimonials Section**: Client reviews with 5-star ratings

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or higher
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. **Install dependencies**

```bash
npm install
# or
yarn install
# or
pnpm install
```

3. **Run the development server**

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📝 Customization

### Update Personal Information

1. **Profile Image**: Replace `public/profile.png` with your photo
2. **Personal Details**: Edit content in each page component
3. **Projects**: Modify the projects array in `app/projects/page.tsx`
4. **Skills**: Update skills data in `app/skills/page.tsx`
5. **Contact Info**: Change contact details in `app/contact/page.tsx`

### Styling

- **Colors**: Edit Tailwind config for custom color schemes
- **Animations**: Modify `app/globals.css` for custom animations
- **Fonts**: Update `app/layout.tsx` for different fonts

## 📦 Build for Production
